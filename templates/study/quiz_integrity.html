Underlying Cryptographic Architecture

Upon quiz completion, a canonical string combining quiz_id, topic_id, score, total_questions, accuracy, and completed_at is hashed with SHA-256 and digitally signed using the Elliptic Curve Digital Signature Algorithm (ECDSA SECP256k1). The public key proves authorship without revealing private keys, providing non-repudiation and immediate detection if MySQL records are modified outside the app.
